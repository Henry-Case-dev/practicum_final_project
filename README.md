# Планировщик задач

## Описание проекта
Данный проект представляет собой веб-приложение для планирования задач. Оно позволяет создавать, редактировать, удалять и отмечать задачи как выполненные. Задачи могут быть как разовыми, так и повторяющимися (ежедневное или ежегодное повторение).

* Задания повышенной трудности не выполнялись

## Запуск проекта локально
1. Установите Go (минимальная версия согласно файлу go.mod).
2. Создайте переменную окружения, если необходимо, для указания нестандартного пути к базе:
   ```
   TODO_DBFILE=.../scheduler.db
   TODO_PORT=7540
   ```
3. Запустите сервер командой:
   ```
    go build -o app .
    ./app
   ```
4. Откройте в браузере: http://localhost:7540

## Запуск тестов
1. Проверьте файл `tests/settings.go` – можно задать следующие параметры:
   - Port: 7540
   - DBFile: ../scheduler.db
   - FullNextDate: false
   - Search: false
   - Token: (оставьте пустым)
2. Запустите тесты командой:
   ```
   go test -count=1 ./tests
   ```
